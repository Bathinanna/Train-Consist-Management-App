## UC1: Initialize Train and Display Consist Summary

### Goal
Initialize the Train Consist Management App and display the initial state of the train.

### Concepts
- Class and `main()` method
- `static` keyword
- `List` and `ArrayList`
- `size()`
- Console output

### Implementation Summary
- Start the app with a welcome message
- Initialize an empty `List<String>`
- Print initial bogie count and current consist

### Sample Output
```text
=== Train Consist Management App ===
Train consist initialized.
Initial bogie count: 0
Current train consist: []
System ready for further operations.
```
